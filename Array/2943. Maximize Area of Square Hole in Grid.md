
##  Intuition

Removing bars creates **continuous gaps** in the grid.
A **square hole** can exist only when there is a **continuous gap both horizontally and vertically**.

The size of the square is limited by:

* The longest **consecutive removed horizontal bars**
* The longest **consecutive removed vertical bars**

Since a square must fit in **both directions**, its maximum side length is determined by the **smaller of the two gaps**.
---

##  Approach

1. **Sort** the arrays of removed horizontal and vertical bars.
2. **Scan each array** to find the length of the **longest consecutive sequence**.
3. Compute the maximum square side as:

   ```
   side = min(maxH, maxV) + 1
   ```
4. Return:

   ```
   area = side × side
   ```

---

##  Complexity

* **Time Complexity:** `O(n log n + m log m)` due to sorting
* **Space Complexity:** `O(1)` (excluding input)

---


##  Code
```
class Solution {
    public int maximizeSquareHoleArea(int n, int m, int[] hBars, int[] vBars) {
        Arrays.sort(hBars);
        Arrays.sort(vBars);

        int maxH = longestConsecutive(hBars);
        int maxV = longestConsecutive(vBars);

        int side = Math.min(maxH, maxV) + 1;
        return side*side;
    }
    private int longestConsecutive(int[] arr){
        if(arr.length == 0) return 0;

        int currSeq = 1;
        int maxSeq = 1;

        for(int i = 1; i < arr.length; i++){
            if(arr[i] == arr[i-1]+1){
                currSeq++;
            }
            else{
                currSeq = 1;
            }
            maxSeq = Math.max(currSeq, maxSeq);
        }
        return maxSeq;
    }
}
```
